# Orbit Escape

Elockman Game Studio'nun altın roketli marka kimliğiyle tasarlanmış, tek parmakla oynanan kısa bir 3B uzay kaçışı.

## Oynanış

- Uçuşlar 45 saniye sürer.
- Üç rotadan biriyle ilerle; kırmızı ışıklı asteroitlerden kaç.
- Altın enerji çekirdeklerini topla; üç kalkan hakkın var.
- Uyarı bandı yaklaşan asteroitin hangi rotada olduğunu söyler.
- Çarpışınca oyun nedenini gösterir; uçuş raporunda son çarpışma ve şerit görünür.
- Günün rotası aynı gün tekrar oynandığında aynı düzeni kullanır.
- Telefonda kaydır veya ekrandaki okları kullan. Bilgisayarda ok tuşları ya da A/D çalışır.
- P tuşu veya duraklat simgesi uçuşu bekletir.
- İlk açılıştan sonra web uygulaması çevrimdışı oynanabilir ve telefona eklenebilir.

## Başlat

start-game.bat dosyasına çift tıkla. Yerel sunucu açılır ve oyun tarayıcıda başlar. Bunun için Node.js gerekir. İstersen index.html dosyasını doğrudan açıp da oynayabilirsin; uygulamayı telefona kurmak için yerel sunucuyu kullan.
